# My Singing Shapes Fan Website

This folder contains:
- `index.html` — fan guide homepage, character cards, search, and an element-combination explainer.
- `game.html` — the original playable game file supplied for this project.

## Preview locally
Open `index.html` in a web browser. Keep `game.html` in the same folder so the Play button works.

## Deploy to Render (Static Site)
1. Create a GitHub repository, for example `my-singing-shapes`.
2. Upload `index.html`, `game.html`, and this `README.md` to the repository's root.
3. In Render, choose **New + → Static Site** and connect that GitHub repository.
4. Set **Branch** to `main`.
5. Leave **Build Command** blank.
6. Set **Publish Directory** to `.` (a single dot).
7. Click **Create Static Site** / **Deploy**.

Render will provide a public `onrender.com` address. Each time you push updates to the GitHub repository, Render can redeploy the site.

## Notes
- The breeding section is intentionally an explainer, not a guaranteed combo chart. The supplied game's code uses island-specific hidden recipes and chance-based outcomes; the guide does not claim to reveal secret pairings.
- This is an unofficial fan-made site. Make sure you have permission to publish any game assets or code you do not own.
